# Эхо

Личный музыкальный сайт: «Моя волна» с рекомендациями, поиск, ИИшка для плейлистов, скачивание MP3/WAV/FLAC, вход по коду на почту и загрузка своей музыки администратором.

## Запуск на этом компьютере

Дважды кликните `start.bat` или выполните:

```bash
.venv\Scripts\python server.py
```

Сайт откроется на http://localhost:8765

## Настройки (`.env`)

| Параметр | Что это |
|---|---|
| `SMTP_*`, `MAIL_FROM` | ящик, с которого уходят коды входа |
| `ADMIN_EMAILS` | почты администраторов через запятую: им доступна загрузка музыки |
| `SITE_URL` | адрес сайта; при `https://` cookie входа ставится только по HTTPS |
| `GPTUNNEL_API_KEY`, `GPTUNNEL_MODEL` | ИИшка через gptunnel.ru; без ключа работает подбор по правилам |
| `JAMENDO_CLIENT_ID` | бесплатный ключ с devportal.jamendo.com: добавляет треки с FLAC-скачиванием |

`.env` содержит пароли: не публикуйте его и не кладите в git (он уже в `.gitignore`).

## Откуда музыка и какое качество

- **Audius**: полные треки, MP3 320 kbps. Скачать можно только треки, где автор разрешил скачивание. WAV собирается в браузере из MP3 320 (больше данных, чем в MP3, там нет).
- **Jamendo** (с ключом): скачивание FLAC без потерь, WAV 24 бит из FLAC, MP3.
- **Своя музыка**: администратор загружает WAV/FLAC/MP3, файл хранится и отдаётся без перекодирования.

## Перенос на music.maxsim.space

Нужен сервер с Python 3.10+:

1. Скопируйте папку целиком (без `.venv` и `data`).
2. `python -m venv .venv && .venv/bin/pip install anthropic pydantic` (пакеты нужны только для запасного ИИ через Claude).
3. В `.env` оставьте `SITE_URL=https://music.maxsim.space`.
4. Запустите `python server.py` как службу (systemd) и проксируйте домен на порт 8765 через nginx с HTTPS. В nginx поставьте `client_max_body_size 500m;` для загрузки треков.

Данные (пользователи, сессии, загруженные треки) лежат в папке `data/`: её стоит бэкапить.
